# Calculator Website

A simple web-based calculator built with HTML, CSS, and JavaScript.

The calculator allows users to perform basic mathematical calculations through a simple and responsive interface.

## Features

- Perform basic arithmetic operations
- Addition, subtraction, multiplication, and division
- Clear calculator input
- Delete the last entered value
- Display calculation results
- Simple and user-friendly interface
- Responsive design for different screen sizes

## Technologies Used

- **HTML5** - Structure of the calculator
- **CSS3** - Styling and responsive layout
- **JavaScript** - Calculator logic and user interactions

## How It Works

The calculator uses JavaScript to handle user input and perform mathematical operations.

When a user enters numbers and selects an operation, JavaScript processes the input and displays the calculated result on the screen.
